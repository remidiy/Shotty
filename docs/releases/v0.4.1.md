**Fix: Shotty no longer keeps asking for permissions you already gave.**

- Builds are now signed with a stable certificate, so macOS remembers Accessibility, Screen Recording and folder access across updates (spec 0006).
- Shotty never shows the Accessibility prompt on every send any more. It asks at most once, then the banner opens the right System Settings page.
- Settings shows the status of both permissions.

**One-time step when updating from 0.4.0 or earlier:** clear the stale entries, then allow Shotty again.

```
tccutil reset Accessibility com.remidiy.shotty
tccutil reset ScreenCapture com.remidiy.shotty
```

Requires macOS 26 or later.
