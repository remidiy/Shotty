First public build of Shotty.

- **Sends to the app you were using.** Work in Cursor, take a screenshot, it lands in Cursor. Terminals get the file path for Claude Code / Codex CLI; chat apps get the image. Pin one app from the ⋯ menu if you prefer.
- **Draggable history.** Every capture is kept in the menu bar panel. Drag one into any app, send it again, or show it in Finder.
- **⌃⇧4 instant capture**, plus a one-click fix for macOS's 5-second floating-thumbnail delay.
- Native translucent UI and a Settings window (⌘,).

Requires macOS 26 or later. Download **Shotty.dmg** and drag Shotty to Applications, or use **Shotty.zip**.
